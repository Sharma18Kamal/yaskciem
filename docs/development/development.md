# Development

## Workflow

1. Restore dependencies.
2. Build the solution.
3. Run unit tests.
4. Validate provider and risk-engine behavior with mock datasets.
5. Package installers and review logs.

## Coding standards

- Follow SOLID and clean architecture
- Keep UI code free from provider-specific logic
- Use async/await and cancellation-aware operations
- Favor reusable abstractions and testable domain services
